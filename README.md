# VÉLOR — Mobility Studio

Demo de locadora de veículos, desenvolvida para o portfólio Or7.dev.

## Desenvolvimento

```bash
npm ci
npm run dev
```

## Deploy

Crie o repositório `locadora-de-veiculos-demo` e configure **Settings > Pages > GitHub Actions**.

URL: https://lorenzo-or7.github.io/locadora-de-veiculos-demo/

As imagens de veículos dependem do serviço externo Unsplash.
